# SRT — SHREE RAM TRAVELS Portal

Modern responsive UX/UI for SRT's public information portals.

## Pages
- index.html — main portal
- company.html — KTC corporate trip portal
- vendor.html — vendor view
- driver.html — driver view
- customer.html — customer view

## Logo
The pages expect the GitHub repository logo at:

`IMG/SRT LOGO.png`

## KTC API
`company.html` is connected to the deployed Google Apps Script API and expects the API to return the safe KTC trip fields, including separate Start Date, Start Time, Start KM, End Date, End Time and End KM.
