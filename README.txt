## Apply

1. Add the CSS from `srt-header.css` to the page stylesheet or inside `<style>`.
2. Replace the existing top branding/header area with the contents of `srt-header.html`.
3. Keep the existing page-specific content below the header.
4. Commit the changes to GitHub.
5. Refresh GitHub Pages with Cmd + Shift + R.
